Mes Projets Réalisés

Projet AP1 : Solution Informatique Nomade Sécurisée

Résumé : Ce projet visait à concevoir un poste de travail mobile hautement sécurisé (Hardening). L'objectif était de réduire la surface d'attaque du système Windows et de créer un "Master" prêt à être déployé massivement.

Technologies & méthodes utilisées :

  • Sécurisation Système : Désactivation de NTLMv1, SMBv1, PowerShell V2 et de l'Auto-run.
  • Protection : Configuration de Microsoft SmartScreen et Exploit Protection.
  • Gestion logicielle : Utilisation de Chocolatey pour l'automatisation des installations.
  • Déploiement : Création d'une image système et clonage avec Clonezilla.

Projet AP2 : Infrastructure Réseau & Services PARCUS

Résumé : Réalisation complète d'une infrastructure virtualisée pour une entreprise. Ce projet intègre la segmentation réseau, la gestion centralisée des utilisateurs et la mise en place d'un centre de services IT.

Technologies & méthodes utilisées :

  • Virtualisation : Déploiement sous hyperviseur Proxmox VE.
  • Réseau : Configuration de pfSense (Pare-feu, gestion WAN/LAN, DHCP).
  • Services de Domaine : Installation de Windows Server 2022 avec Active Directory (AD DS).
  • Gestion de Parc : Mise en place de GLPI sur serveur Debian pour l'inventaire et le helpdesk.
  • Système : Administration Linux avancée (gestion des permissions, paquets et dépannage réseau).
